# 🎯 Fluxo Profissional de Atendimento

Uma aplicação interativa que demonstra o processo completo e profissional de atendimento ao cliente.

## 📋 Sobre o Projeto

Este projeto apresenta um fluxograma visual detalhado de como organizar e gerenciar atendimentos de forma profissional, com simulação prática de uma conversa entre cliente e atendente.

## 🎨 Características

✨ **Fluxograma Visual Completo**
- 5 etapas iniciais de atendimento
- Decisão inteligente baseada na complexidade da demanda
- 2 caminhos diferenciados (resolução imediata vs encaminhamento)
- Etapas finais comuns

💬 **Simulação de Chat Interativa**
- Mockup realista de celular
- Conversa completa entre cliente e atendente
- Indicador de digitação animado
- Animações suaves e responsivas

🎯 **Design Profissional**
- Interface moderna com Tailwind CSS
- Totalmente responsivo
- Ícones do Font Awesome
- Cores e tipografia profissionais

## 📱 Temas Abordados na Simulação

- Organização de atendimento via WhatsApp
- Controle e registro de solicitações
- Classificação de demandas por prioridade
- Diferenciação entre resolução imediata e encaminhamento
- Importância de seguir um fluxo padrão
- Análise de indicadores e padrões
- Pesquisa de satisfação

## 💡 Como Personalizar

Para modificar a conversa do chat, edite o array `scriptConversa` dentro do `<script>` do `index.html`:

```javascript
const scriptConversa = [
    { autor: 'cliente', texto: 'Sua mensagem aqui' },
    { autor: 'atendente', texto: 'Resposta aqui' },
    // ... mais mensagens
];
```
